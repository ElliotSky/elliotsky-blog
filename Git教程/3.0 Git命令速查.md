

1. 本地仓库操作

- **[初始化](https://www.google.com/search?q=%E5%88%9D%E5%A7%8B%E5%8C%96&oq=git%E5%B8%B8%E7%94%A8%E5%91%BD%E4%BB%A4&gs_lcrp=EgZjaHJvbWUyBggAEEUYOTIJCAEQABgMGIAEMgcIAhAAGIAEMgcIAxAAGO8FMgcIBBAAGO8FMgoIBRAAGKIEGIkF0gEJNDE5NWowajE1qAIIsAIB8QXTsbEUSLN5CQ&sourceid=chrome&ie=UTF-8&ved=2ahUKEwj8h83yrpyTAxXwcPUHHU1wFWUQgK4QegYIAQgAEAk)**：`git init` - 初始化当前目录为本地仓库。
- **克隆**：`git clone <url>` - 克隆远程项目。
- **查看状态**：`git status` - 查看文件修改状态。
- **暂存文件**：`git add <file>` 或 `git add .` - 将修改添加到暂存区。
- **提交**：`git commit -m "提交信息"` - 将暂存区内容提交到本地仓库。
- **查看日志**：`git log` - 查看提交历史。
- **回退**：`git reset --hard HEAD^` - 回退到上一个版本。
- **删除**：`git rm <file>` - 删除文件并提交暂存。

1. 分支管理

- **查看分支**：`git branch` (本地), `git branch -a` (所有)。
- **创建分支**：`git branch <branch_name>`。
- **切换分支**：`git checkout <branch_name>` 或 `git switch <branch_name>`。
- **创建并切换**：`git checkout -b <branch_name>`。
- **合并分支**：`git merge <branch_name>` - 将分支合并到当前分支。
- **删除分支**：`git branch -d <branch_name>`。

3. 远程同步

- **拉取**：`git pull <远程仓库名> <分支名>` - 拉取并合并。
- **推送**：`git push <远程仓库名> <分支名>` - 推送本地分支到远程。
- **添加远程库**：`git remote add origin <url>`。
- **查看远程库**：`git remote -v`

4. 常见工作流示例

5. **新建项目**：`git init` -> `git add .` -> `git commit -m "init"` -> `git remote add origin <url>` -> `git push -u origin master`
6. **日常开发**：`git pull` -> (修改文件) -> `git add .` -> `git commit -m "fix: ..."` -> `git push`
7. **分支开发**：`git checkout -b feature` -> (开发) -> `git add .` -> `git commit` -> `git checkout master` -> `git merge feature` -> `git push`

8. 常用技巧

- **暂存变更**：`git stash` - 暂时封存工作区，用于切换分支前。
- **恢复暂存**：`git stash pop` - 恢复之前封存的变更。
- **查看记录**：`git reflog` - 查看所有历史操作，常用于恢复丢失的提交。
