#### 配置查询
```
# 用户名
git config --global user.name

# 邮箱
git config --global user.email
```

#### 初始化仓库
```
# 初始化仓库
git init
```

#### 暂存区管理

> 开发->添加修改到暂存区->暂存区提交到分支

```
# 查看修改状态
git status

# 添加所有修改
git add .

# 添加指定文件
git add index.html

# 提交暂存区到分支
git commit -m "注释：本次修改的内容"
```

#### 日志
```
# 查看日志
git log

# 日志摘要
git log --oneline
```
