##### 1.2 命名，仓库简介
**Repository name：仓库名称**
Github 仓库命名习惯：全小写字母，短横线 `-` 分隔单词

**Public/Private**
可访问权限：
- 公开仓库：所有人可见
- 私人仓库，仅指定人可见

#### 2. 快速开始教程详解
这里在 `/f/Studypath/GitLearn` 创建了一个 `elliotsky-blog` 文件夹，
1. 通过 `echo` 命令创建了一个 README.md，该 md 一般是项目的介绍文档和使用教程，会展示在仓库的首页。
2. `git init` 把当前文件夹初始化为 git 仓库，会自动生成一个存储元数据用的 `.git` 文件夹。
3. `git add` 命令把 md 添加入暂存区。
4. `git commit` 命令把暂存区提交入本地分支，`-m` 把后续字符串存为备注。
5. `git branch -M` 这是一个历史遗留问题：Git 的默认初始分支都叫 `master`，而 Github 的默认分支是 `main`，这里需要靠重命名对齐分支
6. `git remote add` 将远程仓库的地址关联到本地仓库。`origin` 是约定俗成给远程仓库起的默认别名，代表“源”，但并非强制只是习惯。
7. `git push origin main` 命令将本地的 `main` 分支推送到远程仓库 `origin`，`-u` 是 `--set-upstream` 的缩写，可以 记录分支追踪关系，方便下次使用无需参数的 `git push`。

#### 3. 常见报错及其解决
##### 3.1 连接超时

`fatal: unable to access '...': Failed to connect to github.com port 443 after ... ms: Operation timed out`

一般是网络问题，如无法连接国际互联网，连接国际互联网重试即可。
