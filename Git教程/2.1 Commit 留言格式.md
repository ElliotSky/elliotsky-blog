### 一、留言格式
**通常格式：**
```
<type>: <short description>
```
如果写得更完整一点：
```
type(scope): short summary  
  
longer description (optional)  
  
footer (optional)
```
**结构说明：**

| 部分          | 作用                      |
| ----------- | ----------------------- |
| type        | 说明提交类型                  |
| scope       | 影响的模块                   |
| summary     | 一句话总结                   |
| description | 详细说明                    |
| footer      | issue、breaking change 等 |

### 二、最常用的 Commit Type（重点）

| 类型           | 用途          | 示例                                        |
| ------------ | ----------- | ----------------------------------------- |
| **feat**     | 新功能         | `feat: add user login feature`            |
| **fix**      | 修复 bug      | `fix: resolve crash on startup`           |
| **docs**     | 文档修改        | `docs: update README installation guide`  |
| **style**    | 代码格式（不影响逻辑） | `style: format code with prettier`        |
| **refactor** | 重构代码        | `refactor: simplify authentication logic` |
| **perf**     | 性能优化        | `perf: improve image loading speed`       |
| **test**     | 测试相关        | `test: add unit tests for login service`  |
| **build**    | 构建系统        | `build: update webpack config`            |
| **ci**       | CI/CD       | `ci: update github actions workflow`      |
| **chore**    | 杂项（依赖等）     | `chore: update dependencies`              |

### 三、常见的 commit 示例

| 案例   | commit                                   |
| ---- | ---------------------------------------- |
| 新功能  | feat: add dark mode support              |
| 修复   | bug fix: fix login button not responding |
| 小改动  | chore: update package dependencies       |
| 代码优化 | refactor: simplify API request logic     |
|文档更新|docs: add API usage examples
### 四、案例
#### 简单更新

1. feat(order): add order status tracking
2. fix(cart): correct total price calculation when removing items
3. refactor(api): separate validation logic into middleware

#### 复杂更新/专业团队（推荐）

feat(notification): add email notification service  
  
Introduce email notifications when order status changes.  
  
- add email template  
- integrate SMTP service  
- trigger notification on order update
