#### 便捷命令：别名机制
##### git 命令简写
```bash
git config --global alias.<alias> <command>
```

示例
```bash
# 输出分支拓扑图
git config --global alias.graph 'log --all --graph --decorate --oneline'
```

常用别名清单：
```bash
# 完全可以自定义，以下仅供参考
[alias]
  co = checkout
  cob = checkout -b
  coo = !git fetch && git checkout
  br = branch
  brd = branch -d
  st = status
  aa = add -A .
  unstage = reset --soft HEAD^
  cm = commit -m
  amend = commit --amend -m
  fix = commit --fixup
  undo = reset HEAD~1
  rv = revert
  cp = cherry-pick
  pu = !git push origin `git branch --show-current`
  fush = push -f
  mg = merge --no-ff
  rb = rebase
  rbc = rebase --continue
  rba = rebase --abort
  rbs = rebase --skip
  rom = !git fetch && git rebase -i origin/master --autosquash
  save = stash push
  pop = stash pop
  apply = stash apply
  rl = reflog
  last = log -1 HEAD
  logl = log --oneline
  nah = git reset --hard; git clean -df
  gac = git add . && git commit -a -m
  wip = git add . && git commit -a -m 'WIP'
```

如果别名很多，不必一个个设置，可以打开 `~/.gitconfig` 文件，将别名粘贴到 `[alias]` 下即可。

##### shell 命令简写
```bash
git config --global alias.<alias> "!<shell command>"
```

示例
```bash
# 最简示例
git config --global alias.hello "!echo hello"

# 打开可视化面板
git config --global alias.visual '!gitk'
```
