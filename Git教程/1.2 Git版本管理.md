#### 查看版本
```
# 查看版本号
git log --oneline

# 查看所有日志
git reflog
```

#### 版本回退
```
# 回退版本号
git reset --hard 版本号

```

#### VS Code 标记

>修改-添加暂存区-合并

- **M：已修改（Modified）** 
	- 文件已被修改但还没有被添加到暂存区
- **A：已添加（Added）**
	- 文件已经被添加到暂存区，但还没有被提交
- **D：已删除（Deleted）**
	- 文件已经被删除，并且已经被标记为删除，但还没有提交
- **R：已重命名（Renamed）**
	- 文件已经被重命名，这也算作是一种修改，需要被添加到暂存区
- **C：已复制（Copied）**
	- 文件已经被复制，这也算作是一种修改，需要被添加到暂存区
- **U：已更新但未融合（Updated but Unmerged）**
	- 这表示一个文件已经被更新了，但在合并时发生了冲突，需要手动解决冲突后再标记为已解决
